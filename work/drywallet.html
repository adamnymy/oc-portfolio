DryWallet

Role
Sole developer — app, interface, and local data layer
Stack
Flutter · Dart · Hive · fl_chart
Context
Personal project, archived
Status
Not maintained
Source
github.com/adamnymy/drywallet-apk
01

Purpose

DryWallet was a personal project: a finance tracker that works entirely offline. Instead of syncing to a server, it keeps records on the device and uses local charts to show how spending moves over time.

02

Approach

Built in Flutter with Hive for local storage and fl_chart for the balance and cashflow views. The goal was a small, fast tracker with no account, no network dependency, and data that stays on the phone.

03

Status

The project is archived and not maintained. It was my first pass at local-first data modelling in Flutter — on-device storage and charts — and remains public on GitHub as a reference.
