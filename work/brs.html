01 Case study

Barbershop Reservation System

  • 2025
  • Web
  • FYP
Role
Sole developer — design, database, code
Stack
PHP · MySQL · HTML/CSS
Context
Final-year project, UiTM Kedah
Source
github.com/adamnymy/BRS-FYPproject
01

Problem

Walk-in-only booking puts the barbershop’s day on the counter: customers wait for a free chair with no idea when one opens, and the shop can’t see tomorrow’s demand. The brief was a simple system where customers book a slot themselves and staff manage the day from one place.

02

Approach

I designed the schema around bookings as the single source of truth — customer booking for reserving, admin and customer dashboards for managing, with authentication on both sides.

03

Outcome

Shipped as my final-year project and won the FYP Best Website category. It remains my reference build for a full CRUD web app: schema, auth, dashboards, and booking flow.
